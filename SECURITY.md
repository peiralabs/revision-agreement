# Security Policy

This repository contains a specification document and no executable code, so it
has no runtime attack surface of its own.

If you find an error in the specification with security implications — a
requirement that would lead an implementer to build something unsafe, or a
conformance test that would pass a system it should fail — please report it
privately through GitHub's private vulnerability reporting on this repository
rather than opening a public issue.

For ordinary specification errors, ambiguities and counterexamples, a public
issue is the right place.
